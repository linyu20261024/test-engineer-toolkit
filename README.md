# 个人工作资源中心（第一版）

面向测试工程师的独立静态网页，适合部署到 GitHub Pages。

## 使用方式
1. 将 `index.html` 上传到 GitHub 仓库根目录。
2. 在仓库 Settings → Pages 中启用部署（Deploy from a branch，选择 `main` 和 `/ (root)`）。
3. 使用 GitHub Pages 提供的网址访问。建议用 HTTPS 网址，以获得完整的浏览器存储和剪贴板能力。
4. 第一次使用可点击“加载示例数据”，也可以直接新增资源。
5. 定期进入“数据管理”导出 JSON 备份。

## 当前功能
- 七个板块：账号与环境、文件资源、工作工具、业务知识、工作平台、模板中心、工作首页。
- 全局搜索、收藏、卡片/列表视图、分页、最近访问、命令复制。
- IndexedDB 保存资源，localStorage 保存轻量页面设置。
- JSON 备份与恢复；CSV 模板、导入和导出（CSV 可用 Excel 打开）。
- 手机端响应式布局与底部导航。
- 本地文件仅记录路径，不上传文件本身。
- 示例数据是演示内容，请按实际情况编辑或删除。

## 注意
- 数据保存在当前浏览器的当前网站来源中。不同浏览器、设备或网址不会自动同步。
- 清除浏览器网站数据可能导致资源丢失，建议定期导出 JSON。
- 这是纯前端本地资源管理页，没有后端服务。
